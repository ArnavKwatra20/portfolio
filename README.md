# Freelancer Portfolio

A modern freelancer portfolio built with React, TypeScript, Vite, and Tailwind CSS.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Deployment

This app is a static Vite build and can be deployed to:

- GitHub Pages
- Netlify
- Vercel

Typical configuration:

- Build command: `npm run build`
- Publish directory: `dist`

## Project goals

- Showcase services clearly
- Feature conversion-focused case studies
- Present technical skills in a credible, accessible format
- Offer a visible contact path for leads
- Keep a clean, responsive layout optimized for mobile and desktop
